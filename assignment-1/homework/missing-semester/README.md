## 为什么没有放进仓库

1. **非本人作品**：全部内容为 MIT 课程网站的第三方资源，仅作学习参考；
2. **体积过大**：含 `.git` 历史（约 13 MB pack 文件）、视频、图片等共约 31 MB，与作业交付无关；
3. **嵌套仓库问题**：自带 `.git` 目录，直接上传会形成嵌套仓库，在 GitHub 上显示为不可访问的空文件夹。
